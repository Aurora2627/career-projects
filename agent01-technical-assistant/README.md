# 通信技术任务执行 Agent

状态：规划及目录初始化完成，模型实现/正式实验尚未开始。

方向：Agent/后端

对应需求：字节火山方舟核心执行、工具、上下文、后端 JD

## 任务

查询公开通信技术资料，提取参数，调用确定性计算工具，返回带证据的分析结果。

## 实现阶段

1. 不依赖框架的最小工具调用循环
2. 检索与单位校验的计算工具
3. FastAPI 提交/查询/取消任务与 SQLite 状态持久化
4. 超时、有限重试、幂等和上下文预算
5. 结构化 Trace、回放与评测

## 第一阶段起点

先人工编写 20 个任务及确定性答案；开发与最终测试分离。优先公开资料与合成配置，不导入未授权文档。

## 实验与验收

- RAG/固定工作流/Agent 对比
- 任务成功率、工具和参数正确率、证据正确性
- P50/P95 耗时、调用成本
- 错误参数、超时、循环调用、信息不足的故障注入

## 运行环境

后端、工具、SQLite、回放和评测在 Mac；优先 API 模型，本地小型模型仅作为可选后端。无需本地训练 LLM。

不预填效果提升数据；只有可复现的真实结果才进入简历。
