# 实验分析与故障诊断 Agent

状态：规划及目录初始化完成，模型实现/正式实验尚未开始。

方向：Agent/后端

对应需求：字节火山方舟 Trace/Metric/Log、任务回放、调试和工程化 JD

## 任务

读取指定目录内的实验配置、曲线、指标和日志，调用分析工具生成有证据的诊断及下一轮实验建议。

## 实现阶段

1. 固定格式的配置/指标/日志解析
2. SQL 查询、曲线统计和实验对比工具
3. Agent 工具选择、证据引用与建议生成
4. 人工确认后生成新配置；默认不自动启动训练
5. 失败注入、诊断评测、上下文与 Trace

## 第一阶段起点

先制作过拟合、学习率过高、数据加载瓶颈、标签映射错误等 12 个合成案例，标明为合成。后续接入真实项目记录。

## 实验与验收

- 预设故障的诊断准确率、证据引用正确率
- 信息不足时拒绝判断的表现
- 固定规则/单次 LLM/工具型 Agent 对比
- 可重现日志集、耗时/成本和回归测试

## 运行环境

合成日志、工具、服务、可视化和评测全部可在 Mac；真实模型使用 API。可读取多模态项目真实日志，重算训练仍由对应环境承担。

不预填效果提升数据；只有可复现的真实结果才进入简历。
